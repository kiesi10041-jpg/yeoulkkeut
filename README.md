# 잔향 04:17 — 업데이트 내역

## v7.4 — 물건 관찰과 이미지 침식

- 기존 해원의 얼굴·우비를 참고한 실제 사진 이미지 제작 및 앞면/뒷면 관찰 연결.
- 번호표·접수증·명부·점검표에 생성한 종이 재질 적용. 숫자와 문구는 읽기 쉬운 실제 글자로 표시.
- 물건을 보여 주는 문단에서 현장에 소품 표시, 선택적으로 눌러 확대. 기록에서도 이미 본 물건을 다시 살펴볼 수 있게 연결.
- 사진 뒷면의 시각과 서진이 별지에 적은 기억을 구분하고, 아직 듣지 않은 기억과 점검표의 마지막 줄은 미리 표시하지 않도록 처리.
- 학교를 통과한 뒤 명부 사본에 구멍 표시 유지. 해원은 번호표 없는 동행인으로 표시.
- 명부의 “너희가 쓰기 전이다”를 행동과 반응으로 교체하고, 남아 있던 해설형 문단·대사를 추가 편집.
- 침식용 투명 이미지 제작. 수치에 따라 가장자리의 농도와 안쪽으로 번지는 범위가 연속적으로 변화.
- 게이지 채움 막대와 상승/감소 반응 추가. 대사와 선택 버튼의 위치는 유지.
- 높은 침식에서 수신기 외곽에도 이미지 질감 적용. 사진·기록의 내용은 침식으로 변경하지 않음.
- 움직임 줄이기 설정과 시작 화면·결말에서 침식 이미지 정리 처리.
- 소품을 보는 중에는 현장 미확인 신호 알림이 끼어들지 않도록 조정.
- 사용하지 않는 구형 이미지 두 개와 중복된 이전 브라우저 검사 보고서 정리.

## v7.3 — 수신기 미확인 신호

- 정식 방송·답신과 별도로 장소·동료 상태·이미 한 행동에 맞는 미확인 신호 27종 추가.
- 문자 없이 표시등과 잡음만 스치는 경우, 혼잣말, 뒤늦은 지시, 도움이 되는 말과 유인 문장을 함께 구성.
- 침식이 높으면 플레이어의 의사를 대신 말하는 문장도 후보에 포함.
- 선택 가능한 상태나 조용한 서술 문단, 수신기 현재 화면을 잠시 열어 둔 상황에서 확률적으로 발생. 인물이 말하는 문단·위기 연출·다른 메뉴·숨긴 화면에서는 예약 중지.
- 같은 장면에서는 한 번만 추첨. 발생 사이 최소 70초, 한 장당 최대 2회, 한 진행에서 최대 12회로 제한.
- 다시 열기·탭 이동·새로고침으로 같은 장면을 재추첨하지 않도록 저장.
- 화면을 강제로 열거나 새 방송 배지·진동을 발생시키지 않는 작은 현장 표시 추가.
- 수신기 현재 화면 안에 최근 미확인 신호 6건을 별도 보관. 정식 답신과 직접 관찰 기록에는 섞이지 않음.
- 간섭음 전용 설정 추가. 음소거 상태에서도 미확인 문자는 확인 가능.
- 간섭음에는 부드러운 마찰음·숨소리 같은 질감을 사용하고 중요한 효과음이 시작되면 잦아들도록 연결.
- 미확인 신호만으로 침식·인벤토리·선택·결말이 변경되지 않음.
- v7.2의 저장 위치와 읽던 문단 유지.

## v7.2 — 동행·규칙·선택의 연속성 보강

- 첫 배를 기다리는 목적과 문자 수신기를 가져가는 경위를 초반에 연결.
- 번호로 소개했을 때와 바깥 상황을 물었을 때 나래의 첫 응답을 구분.
- 두 번 두드리는 부탁을 실제로 방송에 반응이 늦는 모습 뒤에 배치.
- 골목에서 기다리면 짧은 종과 긴 종을 순서대로 경험하도록 대사·음향 연결.
- 묻지 않은 수신기 안내를 들었다고 말하던 창고 대사 수정.
- 나래를 기다린 경우·서둘러 끌고 간 경우, 창고 문을 무리하게 당긴 경우, 명부를 지운 경우의 후속 반응 추가.
- 반복되는 정답 해설을 인물의 말·표정·손동작과 현장 결과로 교체.
- 학교 건물을 나온 뒤 도윤이 이름을 소개하도록 정리.
- 수신기가 꺼져 있어도 연결된 녹음기가 재생 중인 상황을 앞뒤 장면에 연결.
- 물에 남겨 둔 약 가방 회수와 방수 주머니의 메모를 후속 장면에 연결.
- 수호 합류 뒤 시장 이동·부두 인원 확인·결말의 등장을 보완.
- 이번 진행에서 직접 본 번호·소지품·경첩·배선·회복 반응을 장소와 함께 기록 메뉴에 보관.
- 일부 유인 문장은 낮은 침식에서 끊겨 보이고 높은 침식에서는 매끈하게 보이도록 변경. 이미 받은 문장과 현장 관찰은 이후 침식 변화로 바뀌지 않음.
- 달력의 날짜를 묻는 행동을 첫 회차에도 현장 단서로 시도할 수 있게 변경.
- 감염 출항·서둘렀던 출항·동행을 기다리는 결말 등의 설명을 구체적인 사건과 인물 반응으로 교체.
- 대사 분할 길이를 줄이고 모바일 선택 영역의 최소 터치 크기와 작은 화면의 위험 형체 표시 보완.
- 기존 진행은 유지하면서 수정된 장면의 첫 문단부터 읽도록 저장 호환 처리.

## 행동·장소별 음향 보강

- 대화 선택마다 반복되던 공통 효과음을 제거하고 실제 이동에만 발소리를 연결.
- 나무 바닥·돌바닥·젖은 바닥의 발소리를 구분하고 세 걸음의 간격과 잔향을 추가.
- 문고리·문 삐걱임·닫힘, 종이 마찰, 밸브 회전, 흐르는 물의 소리를 분리.
- 효과음에 짧은 시작과 감쇠·공간 잔향을 적용.
- 여덟 장소·상황용 배경음을 각각 96초로 재구성하고 고요한 구간·악기 진입·환경 질감에 변화 추가.
- 장소 전환 시 약 4–7초에 걸쳐 배경음이 겹쳐 바뀌도록 변경. 효과음 중에는 배경음이 조금 낮아짐.
- 새 방송을 수신 화면에서 처음 확인할 때만 짧은 잡음을 재생. 이미 읽은 방송·단순 열기·탭 이동에는 잡음을 재생하지 않음.
- 질문에 새 답신이 도착할 때에도 잡음은 한 번만 재생.

## 핵심 구간의 플레이·음향·여운 보강

- 학교에서 명부 사본과 번호표 세 장을 직접 대조해 내미는 조작 추가.
- 다른 번호표를 내밀면 통과되지 않고 형체의 반응을 확인하도록 연결.
- 창고에서 회색 관의 개방·수위 관찰·마개 잠금·문 열기를 직접 조작하도록 변경.
- 수위가 다르거나 관을 연 채로는 문을 통과하지 못하도록 연결.
- 마지막 인계서에 이상 발화·현재 응답·출력선 상태를 직접 작성하는 과정 추가.
- 작성한 내용에 따라 공개 인계 또는 잘못된 일반 출항 결과로 연결.
- 나래의 두 번 두드리기 부탁을 초반·중반·마지막 선택으로 연결.
- 마지막에 약속을 기억한 경우 전용 결말 이미지와 후일담 추가.
- 초면의 자기소개와 플레이어의 초반 말투 보완.
- 창고의 해결 방법을 미리 설명하던 문장을 관찰 가능한 사실 중심으로 수정.
- 학교·배수시설·자료실·새벽용 원본 배경음 네 곡 추가.
- 장소와 결말에 따른 배경음 선택 및 번호표·밸브·두드림 효과음 연결.
- 시작 화면의 소리 토글 추가, 새 기록은 소리를 켠 상태로 시작하고 기존 설정은 유지.
- 현장 조작 진행을 저장하고 불러오도록 확장.
- 인계서 입력 중 화면이 맨 위로 돌아가던 불편 수정.

## 수신·대화 화면 안정화

- 무전기 형태를 넓은 문자 화면과 세 개의 키가 있는 단말기 이미지로 변경.
- 기기의 외곽과 버튼이 잘리지 않도록 표시 비율과 화면 위치 조정.
- 수신기 내부 메뉴를 수신·이전 방송·교신으로 정리.
- 수신기 안의 사건 기록 버튼 제거, 기본 메뉴의 기록만 유지.
- 대화 영역과 진행·선택 영역을 별도 영역으로 분리.
- 모바일 세로 화면에서 선택 영역을 하단에 고정.
- 모바일 가로 화면에서는 대화와 선택을 좌우로 분리.
- 대사를 넘기거나 장면이 바뀌면 대화 스크롤을 처음으로 복원.
- 긴 대화에 읽기 방향 안내 추가.
- 작은 화면·큰 글자에서의 메뉴 줄바꿈과 선택 영역 배치 보완.

## 이동·장면 연출 정리

- 장소를 고르는 이야기 선택 후 목적지 장면이 바로 이어지도록 변경.
- 본편 이동 때마다 지도를 다시 조작하던 절차 제거.
- 지도는 주변을 자발적으로 살펴보는 보조 기능으로 변경.
- 해솔리 지도 배경 이미지 추가 및 실제 위치 표시 연결.
- 현관을 나가기 전과 진행 중인 위기에서 지도 이동으로 벗어나는 연결 차단.
- 장소가 바뀔 때 출발 위치와 도착 장소를 짧게 표시.
- 문틈의 손, 학교의 형체와 종이, 시장의 천, 창고의 역류, 수신 이상을 장면별 연출로 구분.
- 위험 장면의 간섭을 배경뿐 아니라 대사·선택지 주변으로 확대.
- 해당 상황이 끝날 때까지 연출을 유지하고 안전한 장면과 시작 화면에서 해제.
- 형체를 만나기 전 미리 드러내는 표현과 중복된 괴물 표시 제거.
- 학교의 형체 이미지를 종·명부·종이로 가려진 얼굴에 맞춰 교체.
- 움직임 줄이기를 켜도 정적인 위험 단서와 문장은 유지.
- 위기 진입음과 새 방송 알림음이 동시에 겹치지 않도록 우선순위 조정.
- 기존 저장의 미완료 지도 이동은 이어하기에서 이미 선택한 목적지로 연결.
- 시작 화면의 표기를 ‘개발판’으로 변경.

## v6.3.0 · 화면 구성과 기기 조작 정리

- PC 도구를 오른쪽 세로 메뉴로 분리하고 침식 상태를 메뉴 상단에 배치.
- 모바일 도구를 하단 메뉴로 분리하고 침식 상태를 상단에 배치.
- 대사창의 큰 최소 높이와 여백 제거, 얼굴·이름·본문 중심으로 압축.
- ‘지금 말하는 사람’ 등 반복되는 화자 보조 설명 제거.
- 본문 교신 패널의 기기 그림과 상태 표시 크기 축소.
- 수신기 외부 팝업 상자와 기기 아래의 중복 기능 목록 제거.
- 기기 그림의 조작부에 수신·이전 방송·교신·기록 버튼 연결.
- 받은 답을 먼저 표시하고 보낸 질문은 펼쳐 보기로 변경.
- 기기 화면 안에서 긴 내용을 읽을 수 있도록 스크롤 안내 추가.
- 세로·가로 모바일 화면 및 큰 글자 배치 보완.
