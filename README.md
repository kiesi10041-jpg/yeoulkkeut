# 잔향 04:17 — v8.5.0 업데이트

## 플레이어가 직접 하는 행동

- 시장에서 나래의 연결을 동료가 자동으로 분리하던 장면을 변경했습니다. 벽을 두 번 두드려 반응을 보거나, 나래의 동의를 받은 뒤 짧은 연결선을 직접 뺍니다. 선을 분리해야 휴식·이동을 고를 수 있습니다.
- 두 번 두드리기는 반응을 잠깐 돌려놓지만, 켜진 녹음기를 끄는 행동을 대신하지 않습니다. 기다려 준 경로와 팔을 당긴 경로의 나래 반응은 분리 뒤에 다르게 나옵니다.
- 원본 입력 조사에 실제 조작을 추가했습니다. 원본에서 빠진 문장과 호출선을 고르고, 공용 출력을 분리한 뒤 시험합니다. 잘못 시험하면 흔적과 침식 비용이 남으며 수정할 수 있습니다.
- 6번 결말에서 04:17의 원본 기록, 누락된 보류 문장, 새 응답이 기존 안내와 다른 점을 회수합니다. 현재 결말을 후속편 안내로 대신하던 문구를 삭제했습니다.
- 6번 뒤 열린 장소별 호출 기록 선택은 같은 결말 안에서도 남기는 기록이 달라집니다.

## 반복과 출항 준비

- 결말에 **마지막 선택부터 다시**를 추가했습니다. 이미 끝낸 구조·서류·배치를 되풀이하지 않고 실제 마지막 판단으로 돌아갑니다. 새로 얻은 결말 단서도 다음 선택에 적용됩니다.
- 이번 장 재시작과 처음부터 다시 시작은 함께 유지했습니다.
- 출항 준비는 인원표에서 정한 자리와 인계 응답을 이어받습니다. 같은 자리를 다시 세 번 입력하거나 같은 응답을 또 받을 필요가 없습니다. 자리 변경을 선택하면 다시 정할 수 있습니다.
- 잘못 정한 자리를 그대로 출발하면 기존 승선 사건이 발생합니다. 멈춰 수습하는 행동은 여전히 필요합니다.
- 연결한 적 없는 공용 단자에서 기기를 뽑으라는 문구를, 소리를 끄고 차폐함에 넣는 실제 행동으로 바꿨습니다.

## 대사·물건·행동의 연속성

- 번호표를 말없이 제출했는데 다음 장면에서 “17번입니다”라고 말한 것으로 처리하던 오류를 수정했습니다.
- 나래와 함께 가기로 정하기 전에 동료 목록에 먼저 들어가던 표시를 수정했습니다.
- 선반을 받치기 전에 지문에서 이미 의자를 넣어 버리던 행동을 제거했습니다. 받침 선택과 추가 밀기의 결과가 실제 순서대로 이어집니다.
- 펌프 장면에서 같은 약 가방을 두 번 건지던 행동을 한 번으로 합쳤습니다. 젖은 약 봉투와 방수 주머니의 차이는 유지했습니다.
- 자료실의 출력선 조사와 실제 분리를 구별했습니다. 동의 전에 선을 빼거나 명찰을 두 번 거는 지문을 수정했습니다.
- 아직 일어나지 않은 시장 판자 사건을 나래가 과거처럼 말하던 대사를 방송실에서 겪은 일로 바꿨습니다.
- 서진의 23번, 번호표가 없는 해원, 수호가 실제 녹음한 문장, 중계실 41번 원본 인용을 일치시켰습니다.
- 제출한 번호표와 돌려받은 출입 확인 조각을 구별했습니다.
- 학교에서 이름을 말했을 때 명부에 잡히는 대상이 발화한 17번임을 명확히 했습니다. 명부 정정을 두 번 실패한 결과는 이름을 말한 경로와 별도로 설명합니다.
- 도윤의 자리만 잘못 정했는데 해원까지 떨어졌다고 서술하는 식의 조건 오류를 수정했습니다. 실제 선택한 위험에 해당하는 결과만 나옵니다.
- 지문의 ‘나/너’ 혼용을 본문·조건 지문·결말 추가 문단까지 정리했습니다. 인물끼리 상대를 부르는 대사의 ‘너’는 유지했습니다.
- 구조 뒤 도윤 설명은 원본 16개에서 10개, 해원 설명은 13개에서 8개 문단으로 정리했습니다. 실제 표시 수는 진행 조건에 따라 다릅니다.
- 진료소의 잘못된 호출을 기다린 경로에는 손바닥의 흔적·치료와 침식 비용이 남습니다. 동료가 자동으로 모두 되돌려 놓는 흐름을 줄였습니다.

## 그림과 화면

- 1·2·3·4·6·8·9·10·11·12번 결말 그림을 사건에 맞춰 새로 제작했습니다. 대기실 달력, 이름을 따라 하는 문밖, 남겨진 나래, 부두 계단, 원본 입력함, 육지 인계, 학교의 빈자리, 선반 붕괴, 침수, 닫히는 천 안을 구별합니다.
- 2번과 10번의 동일 그림, 3번과 8번의 공용 그림을 분리했습니다.
- 나래의 손목 이상과 자세 변화를 표현한 전용 인물 그림을 추가했습니다. 손목 표시를 누르면 검은 선을 확대해 볼 수 있습니다.
- 침식 표시를 **내 침식**으로 바꿨습니다. 나래의 증상과 플레이어 수치를 혼동하지 않도록 했습니다.
- 수문을 잘못 돌린 첫 번째와 두 번째의 수위·문구·배관 상태가 다르게 보입니다.
- 결말 그림은 전체 구도를 보존하고 별도로 확대할 수 있습니다. 결말 위에 이번 선택의 결과를 짧게 표시합니다.
- 결말 기록은 새로 플레이한 실제 조건 문장·추가 문단·그림을 보관합니다. 다시 열 때 다른 경로의 기본 문장으로 바뀌지 않습니다.
- 원본 조사창에서 항목을 고를 때 화면·초점이 처음으로 돌아가던 문제를 수정했습니다.
- 이름이 알려진 화자의 빈 초상을 물음표로 표시하던 부분을 정리했습니다.
- 변경된 스크립트와 결말 이미지의 캐시 식별자를 갱신했습니다.
