# 잔향 04:17 — 여울끝 v6.0

새 구조를 적용한 「첫 방송」 개발본입니다. 대합실·골목·부두·중계실의 21개 장면과 결말 6개, 새 배경 2개, 재사용 이미지, 배경음 4곡 및 효과음을 포함합니다. 기존 v5.27의 33개 엔딩 전체를 이식한 출시 완성본은 아닙니다. 기존 v5.27 압축본은 별도로 보관되어 있습니다.

## 실행

압축을 풀어 index.html을 엽니다. 서버에 배포할 때는 index.html, style.css, app.js, engine.js, story.js, icon.svg와 assets 폴더를 같은 구조로 올립니다. 실행에 npm 설치는 필요 없습니다. GitHub에는 ZIP 자체 대신 압축을 푼 파일을 올리세요. 새 파일을 기존 index.html 위치에 교체하며 assets 폴더를 중복으로 감싸지 않습니다.

파일을 직접 열었을 때 저장 지원은 브라우저별로 다를 수 있습니다. 실제 서비스는 같은 HTTPS 주소에서 사용하고, 교체 전 설정에서 기록을 내보내세요. 이 파일은 기존 GitHub 사이트에 자동 업로드되지 않습니다.

## 이번 구조

- 항상 깨끗한 시작 화면을 먼저 표시합니다. 높은 침식의 저장을 불러오려면 이어하기를 선택합니다.
- 마을 이름은 여울끝입니다. 시작·페이지 설명·공유용 이미지 메타데이터에 적용했습니다.
- 현장에서는 대사 한 덩어리씩 읽고 최대 3개 행동 중 선택합니다. 모바일은 위 이미지·아래 읽기, PC는 좌 이미지·우 읽기로 나눕니다.
- 수신기에는 현재 안내와 이전 방송 1건이 있습니다. 이전 방송 재생과 새 질문은 침식을 소비하지만, 이미 받은 내용을 다시 읽거나 메뉴를 여는 행동은 소비하지 않습니다.
- 접수하는 존재는 이름과 번호에 다르게 반응합니다. 같은 조건에서는 같은 결과가 나옵니다. 무작위 반복 괴물 조우는 없습니다.
- 나래의 이상은 방송보다 먼저 나오는 발화와 행동에 나타납니다. 전원을 끊거나 동행·출항하는 선택이 결과로 이어집니다.
- 결말에서 얻은 사실은 이후 선택을 엽니다. 주인공이 이전 회차를 기억한다고 말하지 않습니다.
- 이미 읽은 장면은 건너뛸 수 있습니다. 새로운 장면은 그대로 표시합니다.

## 소리·접근성

기본 소리는 꺼짐입니다. 설정에서 소리를 켜고 배경음·효과음 크기를 따로 조절합니다. 실내·해안·접근·수신용 32초 배경음 4개를 상황에 따라 전환합니다. 특정 전원 차단 장면에서는 음악도 멎습니다. 절차적 합성으로 제작했으며 음성 녹음은 사용하지 않았습니다. 긴 종·노크·스위치·수신 효과음은 Web Audio로 생성합니다.

큰 글자와 움직임 줄이기를 제공합니다. 모든 주요 소리 단서는 대사·자막으로도 제시합니다. 침식 효과는 현장 이미지 안에만 표시하며 대사·선택지·시작 화면을 덮지 않습니다. 탭을 숨기거나 시작 화면으로 나가면 소리를 멈춥니다.

## 저장

v6는 별도 저장 키를 사용해 v5 기록을 수정하지 않습니다. 서로 다른 구조이므로 v5 진행을 자동 변환하지 않습니다. v6 내보내기·불러오기를 제공합니다. 손상된 로컬 기록은 복구 키로 백업한 뒤 새 진행을 만들 수 있습니다.

DOM 통합 검사: 개발 의존성을 준비한 뒤 `npm run test:ui`.
