# 잔향 04:17 — 첫 번째 밤 / 확장 베타 v6.2

마을 이름은 해솔리입니다. 대합실에서 시작해 학교·진료소·배수시설·중계실·방송 자료실·시장·부두를 거치는 9장짜리 본편을 연결했습니다. 나래·서진·도윤·해원·윤서·수호의 만남과 사건을 포함합니다. 기존 v6.0 짧은 개편본과 v5.27은 별도 파일로 보관돼 있습니다.

## 분량과 시간

- 작성한 장면 94개, 본문·대사 약 42,605자. 분기와 우회 장면을 합친 수치입니다.
- 우회가 적은 대표 본편 완주 경로: 고유 장면 65개, 행동 선택 71회, 표시 본문·결말 약 32,933자입니다. 모든 분기를 더해서 한 번의 플레이 시간으로 계산하지 않았습니다.
- 결말 12개: 본편 결과 6개와 중간 실패·우회 결말 6개입니다. 실패 결말은 1시간 이전에도 발생하며 해당 장부터 다시 선택할 수 있습니다.
- 1시간 이상 첫 본편 플레이를 목표로 확장했습니다. 분당 350~650자를 읽는다는 가정에서 본문만 약 51~95분입니다. 이 속도는 가정이며 한국어 읽기 속도의 검증된 기준을 뜻하지 않습니다. 실제 사람의 1시간 플레이 실측은 완료하지 않았고 빠른 독서·건너뛰기·공략 사용에서는 더 짧아질 수 있습니다.
- 강제 대기·실시간 타이머·필수 광고·다회차 누적 시간으로 본편 분량을 채우지 않습니다. 재방문 작업대는 짧은 요약으로 바뀝니다. 자세한 수치는 volume-report.json에 있습니다.

## 실행과 업로드

압축을 풀고 index.html을 엽니다. 실행에 npm 설치는 필요 없습니다. 웹 서버나 GitHub Pages에는 index.html과 모든 JS·CSS·icon.svg, assets 폴더를 같은 구조로 올립니다. index.html이 저장소 루트에 있어야 합니다. ZIP 자체를 올리는 것이 아니라 압축을 푼 파일을 올리세요. 이전 저장소는 그대로 두고 새 저장소에서 테스트하는 것을 권장합니다.

공유용 배경은 assets/title.webp입니다. 새 저장소 주소가 확정되면 index.html의 og:image 값을 그 주소의 절대 URL로 바꾸면 공유 이미지 호환성을 높일 수 있습니다. 공개 사이트에는 자동 배포되지 않았습니다.

## 플레이

- 현장 대사는 이전·다음으로 읽고 최대 3개 행동 중 선택합니다. 긴 본문은 짧게 나눕니다. 모바일은 이미지 위·읽기 아래, PC는 이미지 왼쪽·읽기 오른쪽입니다.
- 수신기의 질문과 이전 방송 재생은 한 번씩 비용이 듭니다. 받은 답을 다시 읽거나 기록을 여는 행동은 침식을 늘리지 않습니다.
- 학교의 호명, 문 뒤의 부상자, 창고 수압, 배수 순서, 입력과 출력, 전등 배선, 음성 동의, 시장 통로, 나래의 연결 상태가 실제 선택으로 이어집니다.
- 잘못을 알아차리고 되돌릴 기회를 주는 장면과, 경고 뒤에도 같은 행동을 반복하면 실패하는 장면을 구분했습니다.
- 나래를 쉬게 했는지에 따라 같은 검사 생략 서명도 다른 결말로 이어집니다. 동료를 돕는 선택과 상태를 숨기는 선택을 구분합니다.
- 결말 뒤 얻은 사실은 이후 선택에 남습니다. 주인공이 이전 플레이를 기억한다고 말하지 않습니다.
- 장 시작 체크포인트로 재시도할 수 있습니다. 본편을 처음부터 매번 반복할 필요는 없습니다.

## 소리와 화면

기본 소리는 꺼짐입니다. 실내·해안·수신·접근의 96초 배경음 4개를 상황에 따라 전환합니다. 음원은 절차적으로 합성했으며 음성 녹음은 사용하지 않았습니다. synthesize-audio.py로 재생성하려면 NumPy와 ffmpeg가 필요합니다. 실행용 MP3는 이미 포함돼 있습니다.

배경음·효과음 개별 음량, 큰 글자, 움직임 줄이기를 지원합니다. 주요 소리 단서는 글에도 남습니다. 침식 효과는 현장 이미지 안에만 표시합니다. 시작 화면은 높은 침식 저장이 있어도 정상 화면을 보여 주고, 이어하기에서만 저장 상태를 표시합니다.

기존 제작 이미지와 인물 초상을 재사용했습니다. 이번 확장에 맞춰 모든 사건을 새 그림으로 제작한 것은 아닙니다. 장면별 전용 일러스트·표정 차분·실제 휴대전화 화면 검수는 추가 제작 범위입니다.

## 저장

이 베타는 janhyang-run-v610 / janhyang-memory-v610의 별도 키를 사용합니다. 이전 v5·v6.0 진행을 삭제하거나 자동 변환하지 않습니다. 설정에서 이 베타의 진행을 JSON으로 내보내고 다시 불러올 수 있습니다. 손상된 기록은 복구 키로 백업한 뒤 새 진행을 시작할 수 있습니다.

## 개발 검증

- `npm test`: 분기·장면·결말·체크포인트·수신 비용·저장 검사.
- `npm run test:ui`: jsdom 준비 후 버튼과 저장을 연결한 DOM 통합 검사.
- `npm run report:volume`: 대표 본편 경로의 표시 원고 분량 재계산.

실제 브라우저 렌더링·모바일 실기기·오디오 청취·사람의 완주 시간 검증은 미완료입니다. 자동 검사 통과는 재미나 출시 품질의 검증이 아닙니다. VALIDATION.md와 BETA_TEST.md를 함께 확인하세요.

## v6.2 변경

지도에서 연결된 아홉 장소로 직접 이동할 수 있습니다. 다른 장소로 가는 행동은 지도 이동 후 이어지며, 주변 조사는 진행 중인 사건을 건너뛰지 않습니다. 문을 열기 전에는 대합실을 나갈 수 없습니다. 동료 메뉴와 현장 초상화로 현재 합류한 사람에게 대화할 수 있고, 관찰 기록은 저장됩니다. 수신기는 현재 화면·보관 방송·질문·답신이 구분된 기기 형태로 개편했습니다. 질문과 이전 방송 재생은 기존처럼 한 번만 침식 비용을 냅니다.

79개 문단의 해설·대사를 수정하고, 나래의 존댓말과 말을 놓는 계기를 연결했습니다. 창고 구조·시장 통로·부두 휴식 이미지 세 개를 추가했습니다. 모든 장면이 새 이미지인 것은 아닙니다. 기존 v6.1 저장은 호환하며 수정된 장면의 첫 문단부터 다시 읽습니다.

GitHub에는 압축을 푼 전체 파일을 같은 디렉터리에 교체해야 합니다. assets만 교체하면 기능과 대사가 바뀌지 않습니다. 원격 저장소나 기존 공개 링크는 자동으로 갱신되지 않습니다.

## v6.2.1 표시와 알림 수정

- 선택지가 이미 표시된 마지막 문단에서는 다음 버튼을 숨김. 이전 문단과 페이지 표시는 유지.
- 지도·동료·수신기·기록 및 침식 상태를 대사 영역 상단에 고정.
- 침식 0–24% 안정, 25–64% 간섭, 65–100% 위험을 수치와 게이지로 표시. 클릭하면 비용과 감소 방법 안내. 동료 정체의 자동 판정 표시가 아님.
- 새 방송에 고정 알림과 강조 표시. 수신기를 열면 읽음 처리. 수신음은 소리 설정을 켰을 때 방송당 한 번. 진동은 설정에서 별도로 켜며 지원 기기에서만 작동.
- 나래 초반 존댓말 및 생략 대사 보완. 말을 놓는 동의는 학교 구조 이후.
- PC/모바일 크기 Chromium 화면 확인 및 알림·선택지·전체 경로 DOM 검사 통과. 실제 휴대전화 진동은 미검증.

## v6.2.2 수신기와 화자

생성한 수신기 이미지를 실제 기기 외형으로 적용하고 내부 화면에 현재 방송을 표시합니다. 화면 안의 긴 글은 스크롤할 수 있습니다. 기기의 사건 기록 버튼은 실제 기록을 엽니다. 질문·이전 방송 기능은 기기 아래에 유지했습니다. 장식 다이얼 자체는 별도 조작 기능이 없습니다.

주요 동료 대사에는 기존 인물 에셋의 얼굴과 이름이 함께 표시됩니다. 플레이어의 말은 오른쪽, 상대는 왼쪽에 표시됩니다. 방송과 정체 미상의 목소리는 별도 기호로 구분합니다. 정체가 밝혀지기 전에 얼굴을 미리 공개하지 않습니다.
