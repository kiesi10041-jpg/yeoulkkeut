# 잔향 04:17 — 업데이트 내역

## 이동·장면 연출 정리

- 장소를 고르는 이야기 선택 후 목적지 장면이 바로 이어지도록 변경.
- 본편 이동 때마다 지도를 다시 조작하던 절차 제거.
- 지도는 주변을 자발적으로 살펴보는 보조 기능으로 변경.
- 해솔리 지도 배경 이미지 추가 및 실제 위치 표시 연결.
- 현관을 나가기 전과 진행 중인 위기에서 지도 이동으로 벗어나는 연결 차단.
- 장소가 바뀔 때 출발 위치와 도착 장소를 짧게 표시.
- 문틈의 손, 학교의 형체와 종이, 시장의 천, 창고의 역류, 수신 이상을 장면별 연출로 구분.
- 위험 장면의 간섭을 배경뿐 아니라 대사·선택지 주변으로 확대.
- 해당 상황이 끝날 때까지 연출을 유지하고 안전한 장면과 시작 화면에서 해제.
- 형체를 만나기 전 미리 드러내는 표현과 중복된 괴물 표시 제거.
- 학교의 형체 이미지를 종·명부·종이로 가려진 얼굴에 맞춰 교체.
- 움직임 줄이기를 켜도 정적인 위험 단서와 문장은 유지.
- 위기 진입음과 새 방송 알림음이 동시에 겹치지 않도록 우선순위 조정.
- 기존 저장의 미완료 지도 이동은 이어하기에서 이미 선택한 목적지로 연결.
- 시작 화면의 표기를 ‘개발판’으로 변경.

## v6.3.0 · 화면 구성과 기기 조작 정리

- PC 도구를 오른쪽 세로 메뉴로 분리하고 침식 상태를 메뉴 상단에 배치.
- 모바일 도구를 하단 메뉴로 분리하고 침식 상태를 상단에 배치.
- 대사창의 큰 최소 높이와 여백 제거, 얼굴·이름·본문 중심으로 압축.
- ‘지금 말하는 사람’ 등 반복되는 화자 보조 설명 제거.
- 본문 교신 패널의 기기 그림과 상태 표시 크기 축소.
- 수신기 외부 팝업 상자와 기기 아래의 중복 기능 목록 제거.
- 기기 그림의 조작부에 수신·이전 방송·교신·기록 버튼 연결.
- 받은 답을 먼저 표시하고 보낸 질문은 펼쳐 보기로 변경.
- 기기 화면 안에서 긴 내용을 읽을 수 있도록 스크롤 안내 추가.
- 세로·가로 모바일 화면 및 큰 글자 배치 보완.

## v6.2.3 · 본문 교신 표현

- 수신기 대사를 기기 이미지와 녹색 문자 화면으로 변경.
- 받은 내용은 RX, 교신 사이의 플레이어 질문은 TX로 구분.
- 현장 스피커 방송·녹음은 PA로 구분.
- 주요 동료의 얼굴 대사창 유지.

## v6.2.2 · 수신기 이미지와 화자 표시

- 안테나·표시등·다이얼·스피커가 있는 수신기 이미지 추가.
- 기기 화면에 실제 방송 내용 표시.
- 기기의 사건 기록 버튼을 기록 창에 연결.
- 주요 동료 대사에 얼굴 확대 이미지와 이름 표시.
- 플레이어와 상대의 대사 방향 구분.
- 정체불명 목소리와 방송을 별도 표시.

## v6.2.1 · 메뉴 배치와 수신 알림

- 선택지가 이미 보일 때 ‘선택지 보기’ 버튼을 숨기도록 수정.
- 지도·동료·수신기·기록 메뉴를 대사 영역 상단에 고정.
- 침식 수치·단계·게이지 및 설명 추가.
- 새 방송 알림과 수신기 강조 표시 추가.
- 수신기 확인 시 방송을 읽음 처리하도록 변경.
- 방송별 단발 수신음 및 선택형 진동 설정 추가.
- 나래의 초반 말투와 생략된 문장 보완.

## v6.2 · 이동과 인물 상호작용

- 아홉 장소를 연결하는 지도 이동 추가.
- 장소별 주변 조사와 관찰 기록 저장 추가.
- 동료 초상화를 통한 개별 대화 추가.
- 해설과 대사 79개 문단 수정.
- 나래의 존댓말과 말을 놓는 계기 연결.
- 창고 구조·시장 통로·부두 휴식 이미지 추가.
- 수신기에서 현재 방송·보관 방송·질문·답신 구분.
- 모바일 버튼 크기와 화면 배치 조정.
